# 🎮 GameLite

### Developed by HUMINGO

GameLite is a modern gaming platform designed to help users
discover games, free-to-play games, official game versions,
cloud gaming options, and useful game information.

---

## ✨ Features

- 🎮 Game discovery
- 📱 Mobile-friendly design
- 🆓 Free-to-play game information
- ☁️ Cloud gaming information
- 📦 Game size and compatibility information
- 🔐 Firebase Email & Password Authentication
- 🔵 Google Sign-In
- 📜 Terms & Conditions
- 🌙 Premium dark UI
- 📱 Responsive design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Firebase Authentication
